# 习惯养成战斗营 - 产品文档

> 产品名：勇者乐园（习惯养成战斗营）
> 定位：家庭习惯养成 APP，游戏化打 BOSS，让孩子养成好习惯
> 目标用户：家长（管理者）+ 孩子（参与者）

---

## 一、产品概述

### 1.1 核心理念

通过游戏化机制将日常习惯养成变成一场"勇者冒险"：
- 家长创建任务卡牌、配置奖励、审核完成情况
- 孩子完成任务获得金币和伤害值
- 全家合力攻打 BOSS，完成任务就是"攻击"
- 金币可兑换商城奖励，形成正向循环

### 1.2 角色体系

| 角色 | 权限 | 入口 |
|------|------|------|
| **家长** | 创建/编辑卡牌、管理 BOSS、审核任务、配置商城、管理家庭、查看复盘 | 家长端（5个底部 Tab） |
| **孩子** | 查看/提交任务、打 BOSS、兑换奖励、查看排行 | 孩子端（5个底部 Tab） |

**家庭结构**：一个家庭最多 6 人，至少 1 位家长。孩子通过邀请码加入，家长加入需额外家长密匙。

### 1.3 用户流程

```
注册 → 创建/加入家庭 → 设置角色(parent/child)
家长：创建卡牌 → 配置商城/BOSS → 审核任务
孩子：查看任务 → 提交打卡 → 家长审核 → 获得金币/伤害 → 打BOSS → 兑换奖励
```

## 二、核心功能模块

### 2.1 卡牌任务系统

**任务类型（三层）**：

| 类型 | 分配周期 | 说明 |
|------|----------|------|
| 每日任务 (daily) | 每天自动分配 | 如：刷牙、整理房间 |
| 每周任务 (weekly) | 每周一自动分配 | 需设置有效期范围 |
| 每月任务 (monthly) | 每月1号自动分配 | 需设置截止日期 |

**卡牌属性**：
- 标题、描述、表情图标（15种可选）
- 难度等级（1-5）：简单/普通/中等/困难/史诗
- 金币奖励：5/10/15/25/40（随难度递增）
- BOSS 伤害值：4/8/12/20/30（随难度递增）
- 重复规则（仅每日）：如 [周一, 周三, 周五]
- 有效期（仅周/月）：开始日期 ~ 截止日期
- 分配范围：全部孩子 / 指定孩子 / 不分配

**任务状态流转**：
```
待完成(▶) → 提交打卡(⏳) → 家长审核中
                              ↓
                         驳回(🔄) ← 审核不通过
                              ↓
                         通过(✅) → 发放奖励
```

### 2.2 BOSS 战斗系统

**核心玩法**：完成任务 = 对 BOSS 造成伤害，全家合力击败 BOSS。

**BOSS 血量公式**：
```
maxHp = max(500, 基础总伤害 × BOSS等级系数 × 孩子数量)
```

**单次伤害计算**：
```
实际伤害 = 基础伤害 × 连击加成 × 攻击系数(attackRatio)
```

**BOSS 状态**：草稿(draft) → 活跃(active) → 击败(defeated)/过期(expired)
- 击败后自动重生为新 BOSS（同参数，新 ID）
- 同一家庭只能有一个活跃 BOSS
- 可设置结束时间、每日攻击限制、可重复挑战

**连击加成**（可配置）：
| 连续天数 | 默认加成 | 称号 |
|----------|----------|------|
| 3天 | ×1.1 | 初露锋芒 ✨ |
| 7天 | ×1.2 | 小有成就 ⚡ |
| 14天 | ×1.25 | 坚持不懈 🔥 |
| 21天 | ×1.3 | 连击大师 💪 |

**击杀奖励**：
- 按伤害占比分配扭蛋掉落（4档品级）
- 全员获得金币奖励（默认 100 金币/人）

### 2.3 金币经济系统

**收入来源**：
| 来源 | 说明 |
|------|------|
| 任务完成 | 按卡牌难度 5-40 金币 |
| 全勤奖励 | 当天所有 daily 任务全部通过：20/50/100 金币（连续3/7天） |
| 签到奖励 | 连续签到达里程碑（10%/30%/50%/70%/100%） |
| BOSS 击杀 | 全员共享奖励 |
| 扭蛋开出 | 随机金币 |

**支出渠道**：
| 用途 | 说明 |
|------|------|
| 商城兑换 | 购买家长设置的奖品 |
| 购买扭蛋 | 在扭蛋商城花金币买扭蛋 |
| 金币衰减 | 每月自动衰减 20%（防通胀） |

**段位积分**：与金币获取一致（完成任务 +1 积分），用于排行榜排名。

### 2.4 商城兑换系统

**商品类型**：
- 普通商品：孩子提交兑换 → 家长确认 → 兑现（或拒绝退款）
- 扭蛋商品：直接购买 → 立即获得扭蛋（无需审核）

**段位要求**（兑换门槛）：
| 段位 | 标识 | 最低积分 |
|------|------|----------|
| 青铜 | 🥉 | 0 |
| 白银 | 🥈 | 100 |
| 黄金 | 🥇 | 300 |
| 钻石 | 💎 | 600 |
| 传说 | 👑 | 1000 |

### 2.5 排位系统

**排行榜维度**：积分榜 / 金币榜
**段位**：可配置（默认 5 级，青铜→传说）
**历史**：个人最近 20 周的段位记录

### 2.6 签到系统

**签到定义**：当天完成**所有** daily 任务 + 家长审核通过（不是登录签到）。

**连续签到**：从当天往前推，每天都有签到成功（月度内计算，每月 1 日归零）。

**奖励阶梯**（可配置百分比模式）：
| 完成比例 | 默认金币 | 称号 |
|----------|----------|------|
| 10% | 20 | 初露锋芒 ✨ |
| 30% | 50 | 小有成就 ⚡ |
| 50% | 100 | 坚持不懈 🔥 |
| 70% | 200 | 习惯养成 💪 |
| 100% | 500 | 完美月度 🏆 |

### 2.7 扭蛋系统

**扭蛋来源**：
1. BOSS 击杀掉落（免费，按伤害占比分配）
2. 商城购买（花金币）

**扭蛋品级**：
| 档位 | 名称 | 商城价 | 金币范围 |
|------|------|--------|----------|
| 1 | 青铜扭蛋 🟤 | 30 | 5~55 |
| 2 | 白银扭蛋 ⚪ | 80 | 15~130 |
| 3 | 黄金扭蛋 🟡 | 200 | 40~320 |
| 4 | 钻石扭蛋 💎 | 500 | 80~700 |

**开奖结果**（二选一，互斥）：
- 随机金币
- 兑换券（铜/银/金/传说四档，概率可配置）

**兑换券**：可直接兑换对应段位的商城商品，不扣金币。

### 2.8 家庭管理系统

**加入方式**：
- 孩子：仅需邀请码
- 家长：邀请码 + 家长密匙（6位）

**家长功能**：
- 修改家庭名称
- 管理成员（增删、改角色）
- 查看邀请码和家长密匙

### 2.9 每日复盘（家长）

**月历视图**：展示每天各孩子的任务完成率
- 🟢 绿色 = 全勤（所有 daily 任务 approved）
- 🟠 橙色 = 完成率过半
- 🔴 红色 = 完成率低于一半

**月度汇总**：活跃天数、全勤天数、平均完成率
**日详情**：每个孩子每日任务状态明细（按日/周/月分类）

### 2.10 金币流水

**分类**：收入（earn）/ 支出（spend）/ 衰减（decay）
**维度**：按月份筛选，家长可查看孩子流水
**展示**：当前余额 + 本月收入/支出/积分统计

## 三、页面导航结构

- 兑换记录
- 签到日历

- 我的兑换券
- 扭蛋商城

## 四、UI 设计规范

### 视觉风格
- **主题**：深色赛博朋克风
- **背景**：深色渐变 (#0B0C1F → #16172E)
- **强调色**：霓虹青 (#6AD6FF)、霓虹橙 (#FF6B35)
- **字体**：Plus Jakarta Sans / Be Vietnam Pro / Space Grotesk
- **卡片**：深色表面 + 霓虹发光边框

### 设计规范
- 所有颜色从 `AppColors` 统一引用，禁止硬编码
- 弹框使用 `CustomDialog` 统一样式
- 按钮使用 `DebounceButton` 防重复点击
- Tab 样式：灰色圆角容器 + 主题色选中指示器
